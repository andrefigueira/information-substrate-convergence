# Information Integration Component

> Location: `isc_ai_system/src/isc_ai/information_integration.py`

## Overview

The Information Integrator calculates phi (Phi), the core consciousness metric from Integrated Information Theory. It measures how much information the system generates beyond what its parts generate independently.

## Theoretical Background

### What Phi Measures

Phi quantifies **irreducibility**: how much the whole system contains more information than the sum of its parts.

```
Phi = I(System) - I(MinimumPartition)
```

Where:
- `I(System)` = Total mutual information across the system
- `I(MinimumPartition)` = Information when split at weakest connection

### Interpretation

| Phi Value | Interpretation |
|-----------|---------------|
| 0 | Completely reducible (no integration) |
| 0.1-0.3 | Low integration |
| 0.3-0.6 | Moderate integration |
| 0.6-0.9 | High integration |
| >0.9 | Very high integration |

## Phi Calculation Algorithm

### Step 1: Calculate System Information

```python
def _calculate_system_information(self, states: List[np.ndarray]) -> float:
    """
    Calculate total information in the system using mutual information
    between consecutive layers.
    """
    total_info = 0.0

    for i in range(len(states) - 1):
        # Calculate mutual information between consecutive layers
        mi = self._mutual_information(states[i], states[i + 1])
        total_info += mi

    return total_info
```

### Step 2: Calculate Mutual Information

```python
def _mutual_information(self, x: np.ndarray, y: np.ndarray) -> float:
    """
    Estimate mutual information between two layer states.
    Using a correlation-based approximation for efficiency.

    MI approximation: -log(1 - r^2) where r is correlation
    """
    # Flatten if needed
    x_flat = x.flatten()
    y_flat = y.flatten()

    # Normalize
    x_norm = (x_flat - x_flat.mean()) / (x_flat.std() + 1e-8)
    y_norm = (y_flat - y_flat.mean()) / (y_flat.std() + 1e-8)

    # Correlation as proxy for mutual information
    correlation = np.abs(np.corrcoef(x_norm, y_norm)[0, 1])

    # Convert to information-theoretic measure
    if correlation < 0.999:
        mi_approx = -np.log(1 - correlation**2)
    else:
        mi_approx = 10.0  # Cap for numerical stability

    return mi_approx
```

### Step 3: Find Minimum Partition

```python
def _find_minimum_partition(self, states: List[np.ndarray]) -> float:
    """
    Find the partition of the system that yields minimum integrated information.
    This represents the "weakest link" in the system's integration.

    Tries different bipartitions using itertools.combinations.
    """
    n_layers = len(states)
    if n_layers <= 2:
        return 0.0

    min_info = float('inf')

    # Try different bipartitions
    for partition_size in range(1, n_layers // 2 + 1):
        for partition_indices in combinations(range(n_layers), partition_size):
            partition_info = self._calculate_partition_information(
                states, partition_indices
            )
            min_info = min(min_info, partition_info)

    return min_info
```

### Step 4: Compute Phi

```python
def calculate_phi(self, states: List[torch.Tensor]) -> float:
    """
    Calculate Phi (integrated information) for a list of layer states.

    This is a simplified version that captures the essence of IIT:
    - Measures how much information is generated by the whole beyond its parts
    - Higher Phi indicates more integrated, conscious-like processing

    Args:
        states: List of torch.Tensor layer activations from forward pass

    Returns:
        float: Phi value (non-negative, higher = more integrated)
    """
    if not states or len(states) < 2:
        return 0.0

    # Convert states to numpy for easier manipulation
    state_arrays = [s.detach().cpu().numpy() if isinstance(s, torch.Tensor) else s
                   for s in states]

    # Calculate total system information
    system_info = self._calculate_system_information(state_arrays)

    # Find the partition that minimizes information loss
    min_partition_info = self._find_minimum_partition(state_arrays)

    # Phi is the difference between integrated and partitioned information
    phi = system_info - min_partition_info
    phi = max(0.0, phi)  # Phi cannot be negative

    self.phi_history.append(phi)

    return phi
```

## Optimization Strategies

### Caching

```python
def _hash_state(self, state_data: Dict) -> str:
    """Create hash for state caching."""
    activations = state_data['layer_activations']
    # Use first few values from each layer as signature
    signature = []
    for a in activations:
        flat = a.detach().numpy().flatten()
        signature.extend(flat[:10].tolist())
    return hash(tuple(np.round(signature, 4)))
```

### Approximation Methods

For large networks, use approximations:

1. **Sampling**: Calculate MI on random subsets of neurons
2. **Hierarchical**: Calculate phi at each layer, then combine
3. **Correlation-based**: Use correlation as MI proxy (current approach)

### Performance Benchmarks

| Network Size | Exact Phi | Approximate Phi |
|--------------|-----------|-----------------|
| 512 neurons | ~100ms | ~20ms |
| 2048 neurons | ~2s | ~80ms |
| 8192 neurons | ~30s | ~300ms |
