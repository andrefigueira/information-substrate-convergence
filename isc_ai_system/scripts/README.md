## 🚀 Getting Started

### Prerequisites
```bash
# Install required dependencies
pip install -r requirements.txt

# Ensure you're in the ISC AI system directory
cd isc_ai_system/
```

### Quick Start Guide

1. **Run a Chat Demo**
   ```bash
   python scripts/demos/isc_chat.py
   ```

2. **Train a Conversational Model**
   ```bash
   python scripts/training/conversational.py
   ```

3. **Run Tests**
   ```bash
   python scripts/testing/test_conversational.py
   ```

4. **Generate Reports**
   ```bash
   python scripts/utilities/report_generator.py
   ```

## 🔧 Configuration
